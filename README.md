# Student Performance Analysis

A beginner data analysis project using Python, Pandas, NumPy, Matplotlib, and SQL concepts to explore student performance data.

## 📌 Project Overview

This project analyzes student performance data and demonstrates basic data cleaning, exploratory data analysis (EDA), and visualization.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- SQL

## 🔎 Data Cleaning

- Identified missing values using `isnull().sum()`
- Handled missing Age values using the column mean
- Handled missing Marks values using the column mean

## 📊 EDA

The project calculates:

- Average marks
- Highest marks
- Lowest marks
- Department-wise average marks
- Department-wise highest marks
- Number of students in each department

## 📈 Visualization

Created a bar chart to compare:

**Average Marks by Department**

## 🗄️ SQL Analysis

Practiced SQL concepts including:

- SELECT
- WHERE
- GROUP BY
- HAVING
- JOIN
- Subqueries
- CTE
- Window Functions

## 📁 Dataset

The dataset contains:

- Student ID
- Student Name
- Department
- Age
- Marks

## 🎯 Learning Outcome

This project helped me build a foundation in data analysis and prepare for Machine Learning by learning how to load, clean, explore, and visualize real-world style datasets.
